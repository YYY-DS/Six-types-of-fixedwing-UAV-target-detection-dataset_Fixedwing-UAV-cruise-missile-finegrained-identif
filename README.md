## 数据集概述

本数据集专注于**多构型固定翼无人机与巡飞弹的视觉检测与识别**，服务于低空安防、智慧巡检及空域目标分类。数据涵盖六类典型固定翼飞行器，适配反无人机系统、空域监测及目标型号识别等应用。

## 数据三要素解析

**类别与构型覆盖**
*   数据集定义 **6** 类固定翼飞行器，覆盖 **常规布局**（普通固定翼）、**特殊气动布局**（无尾翼、长机翼）、**垂直起降型**（VTOL）以及 **特殊用途**（巡飞弹、战斗机布局）。
*   类别划分精细，从气动构型到任务用途均有涉及，有助于模型学习不同飞行器的形态特征差异。
*   巡飞弹类别的纳入，反映了现代低空威胁的多样性，具有较强的安防应用价值。

**数据规模与划分**
*   图像总量约 **11514** 张，按约 **7:2:1** 比例划分为训练集（8059张）、验证集（2302张）与测试集（1153张），划分规范。
*   数据规模充足，能支撑多类别细粒度检测模型的稳健训练。
*   支持 **YOLOv8 / YOLOv9 / YOLOv10 / YOLOv11 / YOLO12 / RTDETR** 等主流模型直接使用。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入上述检测框架。
*   图像与标签一一对应，数据结构规范，即拿即用。

## 知识普及：固定翼无人机细粒度识别要点

*   **构型差异**：不同固定翼布局在机翼形状、尾翼配置、机身比例上存在明显差异。例如，无尾翼机型缺少水平尾翼，长机翼机型展弦比显著偏大，这些是模型区分的关键特征。
*   **尺度与视角**：无人机在图像中的大小受拍摄距离影响显著，且俯视、侧视、仰视等角度会改变外观轮廓。需采用多尺度训练与视角增强策略。
*   **背景干扰**：天空、云层等背景较为单一，但鸟类等生物目标可能与小型无人机混淆，需依赖运动模式或纹理细节进行区分。
*   **部署场景**：低空安防系统对实时性要求高，轻量化模型结合边缘计算设备是工程落地的常见方案。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
test: ./dataset/images/test
nc: 6
names: ['VTOL_fixed_wing', 'conventional_fixed_wing', 'tailless_fixed_wing', 
        'loitering_munition', 'fighter_uav', 'long_wing_uav']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
